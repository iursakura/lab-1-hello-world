Лабораторная работа №2:
Вариант: Соседние ячейки. Запросить у пользователя два ID предмета (например, два ингредиента для создания инструмента). Проверить, лежат ли эти предметы в соседних слотах (рядом друг с другом, в любом порядке). Вывести индексы этих слотов или сообщение, что предметы не лежат рядом.

Лабораторная работа №3:
Вариант: Доска объявлений. В input.txt записаны заказы от жителей деревни в формате День_появления | Заказчик | Требуемый_предмет | Награда (например: 2 | Староста | Дерево | 50). Программа должна отфильтровать только те задания, которые уже доступны игроку (где День_появления <= current_day), и проверить по названиям предметов, лежит ли Требуемый_предмет хотя бы в одном слоте inventory. В output.txt вывести список активных квестов, добавив к каждому статус: [ГОТОВО К СДАЧЕ] (если предмет есть в рюкзаке) или [В ПРОЦЕССЕ] (если предмета нет).
