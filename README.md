Программа должна отфильтровать только те задания, которые уже доступны игроку (где День_появления <= current_day), и проверить по названиям предметов, лежит ли Требуемый_предмет хотя бы в одном слоте inventory. В output.txt вывести список активных квестов, добавив к каждому статус: [ГОТОВО К СДАЧЕ] (если предмет есть в рюкзаке) или [В ПРОЦЕССЕ] (если предмета нет).
