Номер последней выполненной лабораторной работы: 4 Приключенческие шаги весёлого фермера
Вариант 8: Башня: Зеркальная комната. Карта замкнута стенами #. На карте всегда генерируется как минимум одна лестница вверх U. Если герой встает на U — генерируется новый этаж, счетчик этажей увеличивается. Выход домой (Q) работает только если герой стоит на лестнице вниз D (генерируется на старте этажа, под персонажем). Башня разделена стеной строго пополам (по вертикали или горизонтали). Во второй половине карты зеркально отображаются все стены из первой. Герой ходит только по своей половине. Если он наступает на специальный переключатель, зеркало посередине исчезает.
